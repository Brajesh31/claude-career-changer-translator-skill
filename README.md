# claude-career-changer-translator-skill

A Claude Code skill for translating professional experience into credible, role-relevant language when moving between careers or industries.

## Overview

Changing careers often means the value of prior experience is not obvious to a new employer. This skill helps identify transferable skills, reframe achievements, explain career transitions, and build a realistic plan for closing gaps.

The goal is to make existing experience understandable to a new audience without exaggerating qualifications.

## Main Capabilities

- Identify transferable skills across industries.
- Translate experience into target-role language.
- Reframe achievements around measurable outcomes.
- Identify gaps between current and target roles.
- Suggest practical ways to build missing skills.
- Develop a clear career-change narrative.
- Tailor summaries and experience descriptions.
- Prepare interview explanations for a career pivot.

## When to Use It

Use this skill when:

- Moving to a new industry.
- Changing job functions.
- Applying for a role with a different title.
- Rewriting a resume for a career pivot.
- Explaining non-linear career experience.
- Identifying which existing skills remain relevant.

## Usage

Invoke the skill when planning or communicating a career transition:

```text
/career-changer-translator
```

Provide your current role, target role, actual responsibilities, achievements, tools used, and any experience you want to emphasize.

## Recommended Workflow

1. Understand the current career and target role.
2. Identify responsibilities and achievements from prior experience.
3. Extract transferable capabilities.
4. Map those capabilities to the target role's requirements.
5. Identify genuine skill gaps.
6. Reframe achievements using the target industry's language.
7. Build a concise career-change narrative.
8. Tailor the resume and interview examples.
9. Check every claim against the user's actual experience.

## Transferable Skill Examples

| Existing experience | Potentially transferable capability |
|---|---|
| Customer support | Communication, troubleshooting, customer insight |
| Project coordination | Planning, prioritization, stakeholder management |
| Teaching | Facilitation, explanation, structured learning |
| Operations | Process improvement, execution, risk management |
| Sales | Discovery, negotiation, relationship management |

These are starting points, not automatic equivalences. Confirm the user's actual responsibilities and results.

## Quality Checklist

- Claims are truthful and specific.
- Achievements include evidence where available.
- Target-role language is used naturally.
- Transferable skills are connected to real examples.
- Gaps are acknowledged rather than hidden.
- Career narrative is coherent.
- Resume content is tailored to the actual role.

## Practical Principle

Do not disguise a lack of experience with inflated language. Show what the person has actually done, explain why it transfers, and identify what they still need to learn.
