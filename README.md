# Career Changer Translator

Translate skills from one industry to another and identify transferable skills for career pivots. Use when the user mentions changing careers, switching industries, career pivot, transferable skills, or moving from one field to another.

## Overview

This repository packages the original skill instructions and keeps the supporting files in their source-relative locations.

## Install

Clone this repository into your Claude Code personal skills directory:

```bash
git clone https://github.com/Brajesh31/claude-career-changer-translator-skill.git ~/.claude/skills/career-changer-translator
```

On Windows, use `%USERPROFILE%\.claude\skills\career-changer-translator` as the destination.

## Use

Claude Code can select the skill when a request matches its description. You can also invoke it directly with `/career-changer-translator`.
